# AWS Cloud Monitoring Project

## Overview
A beginner AWS Cloud Engineer project demonstrating Git, GitHub,
project documentation, monitoring concepts, and automated validation.

## Objectives
- Document AWS monitoring concepts.
- Organize scripts and monitoring configuration.
- Use feature branches and Pull Requests.
- Validate project changes using GitHub Actions.

## AWS Services
- Amazon EC2
- Amazon CloudWatch
- AWS Identity and Access Management (IAM)

## Project Structure
- docs/       Project documentation
- scripts/    Automation scripts
- monitoring/ Monitoring configuration and examples
- .github/workflows/ GitHub Actions automation

## Security
Never commit AWS access keys, passwords, private keys,
or other secrets to this repository.

## Current Status
Documentation and project structure are being developed.
No live AWS resources are deployed by this project yet.
